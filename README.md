# Todo App

## Description

This is a simple Todo application that allows users to manage tasks effectively. You can add, edit, delete, and complete tasks. The app aims to improve productivity by organizing and tracking tasks in one place.

## Features

- Add new tasks
- Edit existing tasks
- Mark tasks as complete
- Delete tasks
- Filter tasks by status

## Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```bash
   cd todo-app
   ```

## Usage

- To add a new task, use the "Add Task" button and enter the task details.
- To edit a task, click on the task and modify the details.
- To mark a task as complete, click the "Complete" button next to the task.
- To delete a task, click the "Delete" button next to the task.
