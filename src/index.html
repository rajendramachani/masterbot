Branch Model

                
main                         ← masterbot code (never touched by agent jobs)
├── {project}-master         ← project root (workflows, scripts bootstrapped here)
│   └── {project}-dev        ← integration branch (PR target for all feat branches)
│       └── feat/        ← agent working branch (one per task)

The Pi coding agent works on feat/<id>, commits its code, and opens a PR to {project}-dev. The code review agent reviews it. If approved, feat-auto-merge.yml squash-merges it.

Get Started

  1. Fork this repository and enable GitHub Actions.
  2. Set GitHub Secrets and Variables as per instructions.
  3. Configure the Event Handler .env file.
  4. Start the Event Handler using the provided workflow.
  5. Build the Agent Docker Image via the respective workflow.
