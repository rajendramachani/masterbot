# Clang Test: Hello World

This directory contains a basic test setup for Clang using a simple C++ "Hello, World!" program.

## Files

- `hello.cpp`: A simple "Hello, World!" C++ program.
- `CMakeLists.txt`: CMake configuration file to build the test.

## Instructions

1. Navigate to this directory: `cd tests/clang`
2. Create a build directory: `mkdir build && cd build`
3. Run CMake: `cmake ..`
4. Build the test: `make`
5. Run the executable: `./hello`

This test serves as a foundation for future Clang test cases.
